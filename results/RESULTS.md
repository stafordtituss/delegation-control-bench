### Where each control lives in the full-chain configuration

| Control | In the Cedar policy | Computed by the PEP |
| --- | --- | --- |
| Operation / purpose / audience in scope | set membership | intersection across every link |
| Resource in scope | boolean check | pattern match against every link (Cedar `like` needs literal patterns) |
| Validity window | time comparison | tightest window across links |
| Revocation | boolean check | status lookup for every link at commit time |
| Revocation freshness | boolean check | age of status at commit |
| Delegation depth | integer comparison | tightest limit across links |
| Chain continuity, no widening, proof per link | boolean check | all of it |
| Principal-level quota | integer comparison | sum across the principal’s agents |
| Credential nonce, replay, audience, expiry | equality and time comparison | replay-cache lookup |
